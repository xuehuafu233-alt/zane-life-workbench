# ZANE Life Workbench

Start with a real question. Let your AI help you make a decision, finish something useful, and continue from your progress next time.

**0.4.1 beta · Five Skills · MIT** · [中文说明](README.md)

Download the [complete package](downloads/zane-life-suite-0.4.1.zip), extract it, and ask a local AI agent to read `开始使用.md` and guide installation. The methods and primary documentation are in Chinese. Choose your own AI host and model; this package does not include an AI subscription.

The five components are a life coordinator, workspace curator, question intent translator, AI identity card builder, and self-insight guide. The original repository URL is retained for continuity.

Start with: “Use the life workbench to help me with this problem. Help me save relevant context only when I need to continue later. My problem is…”

Your goals and values remain yours. Simple requests do not require a workspace. Files, reminders and external actions depend on the host's actual capabilities and your authorization.

See the [installation guide](docs/install.md), [user manual](docs/guide.md), [examples](docs/examples.md), [validation scope](docs/validation.md), and [provenance](docs/provenance.md). Local macOS installation and synthetic AI scenarios have been checked; independent real-user outcomes and every host or operating system have not been validated.
