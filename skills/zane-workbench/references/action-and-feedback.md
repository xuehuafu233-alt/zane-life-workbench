# 行动与反馈

选择清楚后先完成AI能承担的材料、计算、安排、解释、示例或已授权操作。需本人参与的只留真实判断、沟通或现实行动，不把自己准备全部材料作默认下一步。理解或休息可以结束本次任务。

停滞时用发生过的行为区分解释，先读最近一次尝试、当时条件与停下的位置，不从“没做”倒推出不想做或人格问题。

| 当前线索 | 要区分的解释 | 当前可做的帮助 |
|---|---|---|
| 开始后总在同一步停住 | 入口／技能不清，或该步缺资源 | 给该步示例或可用初稿；核资源是否可得 |
| 能做这件事，却被其他约定挤掉 | 容量冲突，或优先级／目标改变 | 比较实际占用和本人仍愿保有的事，再重排 |
| 材料齐全，反复打磨同一部分 | 仍有影响结果的质量问题，或在回避具体评价 | 对照用途找最后一个实质缺口；可行时准备小范围试用 |
| 连续几次都不愿开始 | 方式不合适、恢复不足、条件变化或目标已变 | 从具体经历检验最相关解释，允许换方式、暂停或重新选择 |

只处理命中的分叉，不例行展示整张表。目标已选、触发可辨、行动可行时才用“当……时，我就……”帮助启动。合成对照：课程总在晚间被照护打断，应先按可用时间换学习方式；已有空闲且明确想学，只卡在第一题，则直接给题目示范。两者都没学完，需要的帮助不同。理解与休息也可以是当前成果。

## 反馈改变当前结果

先确定新信息影响哪个前提：

- 识别实际发生了什么，区分自述、工具核验、感受与推测；明确的用户纠正直接采用。
- 比较旧判断与新条件，辨明需要改变与仍成立的部分；结果好坏不单独证明原判断或人格。
- 找直接依赖旧前提的安排、材料、相关事项与阶段方向，实际修改；跨事项按容量方法复核整体组合。
- 按共享协议保留来源和历史、更新唯一状态与入口，检查下次会话会读到什么。无继续行动就不硬建事项。

“信没发出”要撤销等待回复的前提；“目标仍在但每天时间变少”先改方式，不替用户放弃。学习可按学习任务验收，却不代表已在工作应用；没记录不能反推没行动。单次体验可记录，不强迫提炼人生原则。

状态、工具、授权与接续格式遵循[共享任务协议](../../zane-workbench-curator/references/task-protocol.md)。依赖范围由主控判断、整理器落盘检查；不宣称自动依赖图或后台监控。
