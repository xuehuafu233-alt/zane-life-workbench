# 适配已有工作台

读取用户指定目录的规则、导航和当前任务状态。先找四种现有位置：目标与取舍、事实导航、持续事项、成果与反馈。能承接的直接复用；缺一个位置才补一个，不要求改名或迁移完整目录。

已有事件系统时，记录概念映射：它怎样表示“计划、已执行、等待、反馈、完成”，使用什么更新方法，谁是当前写者。不要再运行本包的初始化或事项工具，不在两个系统里维护同一状态。后续请求沿原工具写入，授权和并发规则以宿主为准。

已有 AGENTS、CLAUDE 或其他宿主入口时保留原件，先形成最小差异；用户请求适配所涵盖的可逆修改可直接完成并备份。禁止整份覆盖为本包模板。多端入口只是指向同一真源的适配，不复制多套事实。

如果目标目录在同步盘或多人共用位置，先识别是否有其他写者。iCloud、网盘和共享目录不等于互斥锁。存在正在写入的同一区域时接续或避开；本包的小型文件工具只提供单机并发保护。

旧历史退出默认读取，但不为清爽而删除原件。确需移除用户资产时移入其工作台暂存区，保留恢复方法。

适配验收：同一事实只在一个地方更新；新反馈能改变当前建议；已有事项状态没有被重置；新包没有偷偷变成所有任务的必经流程。
