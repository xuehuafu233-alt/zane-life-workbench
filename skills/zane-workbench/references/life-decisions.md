# 持续生活问题与取舍

不要求多个领域冲突才处理人生问题。同一领域的持续困扰、关系变化、休息体验、学习和方向不清都可从当前问题开始。领域按使用者需要命名；不强制固定分数、优先级上限或补偿义务。

自我认识 Skill 的解释是 AI 暂定判断，写在 decision 或原则候选中；evidence.input 只记本人说过的经历与来源，并标明用户自述。不要把解释写成已证实的性格或他人动机。本人后来认同也只证明其认可，不证明因果。

新反馈到来：保存最少来源→追加 feedback 或 correction→同步更新 decision、outcome 和 next_action→检查依赖此判断的方向、原则与接续卡。旧证据保留；到期不会自动失效或变失败。没有需要继续推进的行动，体验与感受可以只记录，不为满足系统建立事件。

当事项争夺时间、精力、金钱、责任或方向时：说明实际冲突和不可同时满足之处；比较继续、缩小、推迟、停止及其他现实选项；让使用者作出价值选择。用户有明确选择时落实本轮已授权调整；未选择时保存候选，不擅自取消承诺。方向可以暂定，没有唯一北极星也能先完成眼前问题。

决策记录保留当时选项、理由、未知、会改变决定的反馈；本人直觉或担忧确实影响选择时，可作为当时感受记录，不充当外部事实，也不要求额外填表或排序；置信度及复查日期仅在有意义时填写，不制造概率分数。从经历提取原则见 assets/principle.md，单次经验标候选；下次使用时检查边界与反例。

日常工作、金钱与组织问题按实际能力帮助。已安装专业扩展时按需调用；个人与组织资料范围分开，复用已有事项源。没有扩展不阻断当前分析，也不暗示购买即可获得正确答案。

完成按任务本身的验收与证据判断：计划不等于执行，学习完成不等于已经应用，但学习本身是任务时可以按其标准完成。本人自述与工具直接验证的动作分别标明来源；工具已验证的成果无需本人再口头确认。拟行动可留在计划中，不写成已发生；记录没有出现不能反推本人没有行动。
