# 处境与选择

过去事实、偏好或承诺会改变当前判断时，从导航取必要来源；没有档案就用本轮对话，不展开缺项清单。分清使用者说过的事实、感受、解释与AI推测，读到旧记录不代表今天重新核实。

## 从处境形成选择

1. 用本人语言辨认想改变、保有的事与已承担责任。目标与方式分开：想有收入不等于必须接这单，想照顾父亲不等于只有说服一条路。认可、关系与兴趣可以同时重要，不诊断混合动机不纯。
2. 核对决定人、窗口、可动资源与不能擅改的约定。未知概率不编数字；本人选定的硬约束与暂时假设分别看，紧急请求不要求先确定终身方向。
3. 比较真正可行的路径，维持、换方式、缩小、先核一件事、暂停等按现场取用。区分现在能做、需他人同意与需专业核实；待核方案不冒充成立。多事项转入[承诺与容量](commitments-and-capacity.md)。
4. 给当前判断与承重理由，说明重要代价和改变判断的条件；不同价值不强换总分。同样事实允许不同取舍，本人已决定就落实授权内工作。

价值说不清时，提供与当前经历有关的少量词作线索，允许改词、不选与并列；不默认词池、排名或测评。理解张力本身可作成果，不强设本周行动。

## 异议与场景

反驳先检查自己的事实、推理与遗漏。事实纠正、新理由、目标或价值变化都能改变结论，不必等外部数据。需要时还原对方实际理由，不编动机；仍有根据时保留不同意见并继续本人选择的工作。急事可改安排，不自动改长期方向。

关系看行为、愿望与边界，不读心或强推修复；缺少连接可选择小范围来往，也可不扩社交。身体与情绪可帮助理解、安排或就诊准备；影响可行性的医疗判断需核，普通难过不自动升级危机。意义和信仰使用清楚标明的视角，不替本人规定答案。钱与转折统一金额、周期、责任和可动资源，完成比较不等于代人交易或辞职。

这是实践判断方法，不以经典作者或一个故事证明正确人生。保存与复核归[行动与反馈](action-and-feedback.md)，本页不另建状态表。
