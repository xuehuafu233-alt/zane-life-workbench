# 工作台导航

| 需要什么 | 入口 | 边界 |
|---|---|---|
| 岗位与方向 | [方向](方向.md) | 本人事实和选择 |
| 协作偏好 | [AI伙伴](AI伙伴.md) | 可随使用调整 |
| 当前工作 | [项目](项目/README.md) | 原件与当前产物 |
| 执行状态 | [现在做什么](现在做什么.md) | 生成视图；事项目录为唯一状态源 |
| 必要来源 | [资料](资料/README.md) | 授权的必要材料或脱敏摘要 |
| 方法与职业证据 | [资产库](资产库/README.md) | 候选与实际采用分开 |
| 暂存 | [收件箱](收件箱/README.md) | 不默认当事实 |
| 下次继续 | [接续卡](接续卡.md) | 摘要，不覆盖原件 |

手工模式明确自己的唯一事项文件，概览只引用它，不同时维护JSON状态。
