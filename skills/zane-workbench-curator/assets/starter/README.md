# 我的工作台

先把一个当前问题告诉 AI，让它读取本目录的 AGENTS.md 与 SOURCE_OF_TRUTH.md。方向未定也可以开始。

“方向.md”保存你自己的目标，“AI伙伴.md”保存协作偏好，“资料”保存当前必要材料。持续事项由工具维护，概览由事项生成；一次性任务不用登记。

第一次使用应拿到一份真实可用的成果。下一次会话让 AI 从入口读取，检查能否接上已经完成的部分及当前依赖。不会读文件的聊天工具需要你主动提供入口和必要材料。

这是私人工作目录。不要把它整体上传到公开仓库或随 Skill 分享；隐藏目录和备份同样可能含私人信息。.gitignore 只防部分误提交，不控制网盘同步、上传或 AI 模型的数据处理。
