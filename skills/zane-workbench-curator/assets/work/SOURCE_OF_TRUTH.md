# 工作台导航

| 需要什么 | 入口 | 权威边界 |
|---|---|---|
| 组织方向与约束 | [方向.md](方向.md) | 用户事实与选择，未知不补造 |
| AI 偏好 | [AI伙伴.md](AI伙伴.md) | 用户约定，可修改 |
| 经营决定与落地项目 | [项目/README.md](项目/README.md) | 指向当前材料及事项 |
| 持续状态 | [现在做什么.md](现在做什么.md) | 生成视图，事项/*.json 为原件；手工模式另声明唯一真源 |
| 原始输入 | [资料](资料/README.md) | 必要原件或最小授权摘要 |
| 复用方法 | [资产库](资产库/README.md) | 候选与实际采用分开 |
| 暂存 | [收件箱](收件箱/README.md) | 非默认事实 |
| 新会话交接 | [接续卡.md](接续卡.md) | 摘要，不覆盖原件 |

项目或事项变多时再建立局部导航；不用每个附件更新本页。冲突时核对来源与用户纠正，不凭文件名里的“最终版”决定。

战略简报、模型版本及 AI 试点均从相应项目入口定位；业务单元变多时建立局部导航，不预先复制集团目录。组织源数据与个人事项不默认互通。
