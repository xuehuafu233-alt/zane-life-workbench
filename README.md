## 它解决什么

从正在发生的一件事开始，让判断接上自己的生活。

| 想推进的事 | 工作台帮你推进到 |
| --- | --- |
| 比较工作、城市、学习或生活方式 | 看清各条路径的条件与代价，形成自己的选择 |
| 安排工作、家庭和个人计划 | 把时间、精力、现金与已有约定放在一起协调 |
| 理解自己的动机、价值与反复选择 | 从具体经历找到线索，设计现实中的尝试 |
| 已经作出决定，准备把事情做成 | 完成材料、安排动作，并根据实际回应修订 |
| 一件事需要分几次继续 | 保存当前成果与决定，下次从实际进展接着做 |

## 快速开始

### 1. 安装

```bash
npx -y skills add ZanePan2027/zane-life-workbench -g --all
```

### 2. 直接告诉 Agent 你的处境

```text
请使用 zane-workbench。
我在比较两份工作：一份收入更高但通勤长，另一份时间更灵活。
我想兼顾收支稳定和陪伴家人。这是两份条件和我的月度支出，
请帮我比较可行安排，说清每种选择需要承担什么。
```

也可以从一件更小的事开始：

```text
请使用 zane-workbench，把这周的工作和家庭安排放在一起，帮我排一个可执行的计划。

请使用 zane-workbench，根据这些材料，帮我把搬家计划细化到下一步。

请使用 zane-self-insight，结合我刚才讲的几次经历，看看我在这些选择里最在意什么。
```

## 它怎样工作

当前问题进入后，AI 根据任务使用相关方法：理解处境，比较选择，完成成果，接上实际行动。带回新的条件或回应后，再调整受影响的判断和安排。

例如，比较工作时，先算收入与通勤，再放入家庭安排；其中一份工作新增远程办公条件后，重新看时间和生活的平衡。需要分次处理，就保存当前比较与下一步。

| 工作目标 | 主要入口 | 常见产出 |
| --- | --- | --- |
| 理解处境、作选择、安排生活与行动 | `zane-workbench` | 路径比较、具体成果、时间与资源安排 |

## 使用方法

提供当前问题、相关材料，以及眼前最想完成的事。自己的目标、取舍和表达习惯，会随着实际使用逐步进入工作台。

- **作选择时**，比较自己在意的条件、可行路径和代价。
- **要成果时**，直接提出要完成的材料、分析或安排。
- **条件变化时**，带回新事实或实际回应，修订相关成果。
- **准备下次继续时**，让 AI 保存当前进展，并给它下次可读取的位置。

个人工作台保存在你选择的文件夹中。普通聊天中，可以保存一份接续摘要，下次连同必要材料贴回来。
