# 五个组件

日常从人生总控开始，其他组件由问题触发。安装完整仓库后，五个组件会一起可用。

| Skill | 版本 | 作用 |
|---|---|---|
| [`zane-workbench`](../skills/zane-workbench/SKILL.md) | 0.4.1 | 人生总控，当前帮助、选择、接续与反馈 |
| [`zane-workbench-curator`](../skills/zane-workbench-curator/SKILL.md) | 0.3.2 | 按需搭建、维护、来源导航与事项工具 |
| [`zane-question-intent-translator`](../skills/zane-question-intent-translator/SKILL.md) | 0.2.0 | 澄清进展和当前决定，继续完成任务 |
| [`zane-agent-identity-card-builder`](../skills/zane-agent-identity-card-builder/SKILL.md) | 0.2.0 | 定义伙伴的判断方式、行动与记忆边界 |
| [`zane-self-insight`](../skills/zane-self-insight/SKILL.md) | 0.2.0 | 从经历理解价值、动机、能力与行为模式 |

安装：

```bash
npx -y skills add xuehuafu233-alt/zane-life-workbench -g --all
```
