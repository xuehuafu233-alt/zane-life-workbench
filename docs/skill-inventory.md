# 能力目录

| Skill | 用途 | 适合直接调用的场景 |
|---|---|---|
| [人生经营](../skills/zane-workbench/SKILL.md) | 理解处境、比较选择、协调承诺与资源、完成成果并接续 | 处理当前生活与工作问题 |
| [问题转译](../skills/zane-question-intent-translator/SKILL.md) | 从自然语言识别当前进展、决定与问题 | 几种意图混在一起，想先理清 |
| [自我认识](../skills/zane-self-insight/SKILL.md) | 从具体经历理解动机、价值和反复选择 | 主动探索自己的行为与希望 |
| [AI 伙伴设定](../skills/zane-agent-identity-card-builder/SKILL.md) | 定义协作方式、判断习惯与记忆安排 | 想建立长期合作的 AI 伙伴 |
| [工作台整理器](../skills/zane-workbench-curator/SKILL.md) | 保存成果、维护来源与当前事项、跨会话继续 | 要建台、保存、接续或整理已有工作台 |

每个入口都可以按任务单独调用。日常使用人生经营入口，由它选择本轮需要的方法。
