# 来源与取舍

ZANE 从问题澄清、AI 伙伴设定和自我认识三个 Skill，扩展为人生总控、搭建维护与三个方法组件。发布包只包含通用方法、空白模板、工具与虚构示例，不包含作者的人生档案。

## 发布形式参考

参考 [dontbesilent2025/dbskill](https://github.com/dontbesilent2025/dbskill) 在 2026-09-12 可见的 v2.18.40：一句话用途、实际处境与产出、起步输入、图片流程、安装更新、完整手册和来源说明。ZANE 的文案与图示重新创作，没有复用 DBS 的知识库、推文或演示素材；DBS 内容按其自身许可使用。

## 方法启发

- [values-card-sort](https://github.com/drjennyshields/values-card-sort/tree/414a6eb727f8d3720645bbe5d6f37117121abe13)：启发按需提供价值词与现实反思角度。ZANE 没有复制完整词库、页面或固定分堆流程；使用者可以自造、不选或保留多种价值。
- [swarm-discussion-skill](https://github.com/Ischca/swarm-discussion-skill/tree/632ec7ea0ae3a7d57e464e9f803a1737fe290e25)：启发明确建议依据、重审条件与有根据的异议。ZANE 重新编写为按需复核机制，没有复制完整提示词；参考提交 README 声明 MIT，但该提交未找到许可证正文。
- [Personal-Jarvis](https://github.com/toilacube/Personal-Jarvis/tree/64fcc4b3cd82ad3d7299f11292c38e4bc3d6e94e)：参考决策模板中区分直觉、考量与复查的想法；未复制代码、模板正文或日志规则，该固定版本未找到 LICENSE。

这些来源提供设计启发，不证明 ZANE 的实际使用效果，也不表示原作者认可本项目。ZANE 新文本独立编写，未将缺少明确许可的源码重新分发。
