# 使用手册

## 1. 先说眼前的事

用你平时的语言说就可以。带着材料来时，说明想怎样处理；有时间、精力、预算或已有承诺等关键约束，就直接告诉 AI。没有明确长期目标也能开始。

例如：“下个月可能搬家，但工作地点还没定，帮我看看现在该准备什么。”AI 应先处理现在能做的事，区分确定的条件和还在变化的前提。

## 2. 先得到一个有用结果

结果可以是一份文案、一个判断、一段练习、一项安排，也可以是对困惑的更清楚理解。需要追问时，只补会改变当前帮助的信息。你不需要为了简单任务先建立目录或设定 AI 人格。

你可以随时纠正：“这个事实不对”“我想保住休息时间”“我只要一份能直接用的稿子”。AI 应据此修改，而不是反复解释原方案。

## 3. 需要下次继续时再保存

告诉 AI 一个你方便保存的位置。已有资料就沿用，让它先看入口再适配；空白目录可以先保存一个问题和必要来源。无需搬走所有文件，也不用预建所有生活领域。

能运行随包工具时，持续事项由唯一状态文件维护；能写文件但不能运行工具时，用一份 Markdown 记录与简短导航；纯聊天见[接续方法](chat-start.md)。不要并行维护两套“当前状态”。

## 4. 下次从进展继续

把工作台位置提供给新的会话，说“继续上次的事”，并补充现实变化。AI 应读取相关资料，接住已完成部分，继续下一件已授权的工作。

“已经写好计划”“真的做过”“出现反馈”是不同事实。例如计划参加活动不等于已参加，参加一次不等于已经建立稳定关系。记录应保持这些区别。

## 5. 改变时更新旧建议

告诉 AI：“之前准备去外地，现在工作确定留本地。”它应修改搬家、通勤等直接依赖旧前提的安排，保留历史来源。你无需逐份指出所有旧文件。

对重要建议有异议时，AI 应先复查事实和推理。即使没有新外部证据，也可能需要修正；如果仍有依据支持原判断，它可以说明理由，同时尊重你的选择。

## 6. 让方法按需长出来

同类问题经常出现，再考虑做一个可复用模板。某领域资料经常用到，再加导航；维护变得费力，就缩减结构。文件和 Skill 的数量不表示工作台更有用。

你想探索价值或动机时，可以用[自我认识](../skills/zane-self-insight/SKILL.md)；想定义长期伙伴时，用[AI 伙伴设定](../skills/zane-agent-identity-card-builder/SKILL.md)。这些都不必在第一次使用前完成。

## 常见问题

**和普通聊天有什么不同？** 这是一组让 AI 按需获取背景、完成成果、保存、接续和纠错的方法约定。具体表现仍受模型与工具影响，并非独立应用或永久记忆服务。

**一定要创业、追求收入或制定人生目标吗？** 不需要。目标由你决定，关系、休息和体验本身可以有价值。

**能自动提醒我、操作软件吗？** 只有宿主确实提供这些能力，且相应动作获得授权时才能执行。本包本身不提供后台提醒服务。

**已经装过旧三个 Skill 怎么办？** 保留旧修改，按[安装与更新](install.md)比较后升级，不盲目覆盖。

**需要同时安装其他工作台吗？** 人生版可独立使用。专业扩展按需要增加，共装先核对共享组件版本。
