# 从一次工作选择开始

## 说出眼前的选择

```text
请使用 zane-workbench。
我在比较两份工作：A 收入高但通勤长，B 收入稍低但时间灵活。
我现在最在意收支稳定，以及每周能陪家人多少时间。
这是两份条件和我的月度支出，请帮我比较。
```

AI 会结合收入、必要开支、时间和家庭安排，比较不同取舍下的路径，说明哪几个条件最影响判断。

## 把选择展开到生活里

继续说：“把两种选择分别放进一周安排，看看时间和现金是否够用。”

得到具体安排后，你可以调整自己的偏好：“我愿意少一些收入，换每周两个完整晚上。”AI 据此重排选项，帮你看清相应代价。

## 带回新条件

例如：“A 提供每周两天远程办公。”把新信息带回，重算通勤与陪伴时间，再看原来的建议是否仍适合。

## 下次继续

告诉 AI：“把这次比较、我的取舍和下一步保存到工作台。”下次提供工作台位置，读取当前事项即可继续；聊天中可保存接续摘要再贴回来。

同样的方式也适用于搬家、学习、家庭安排和个人项目。从正在发生的一件事开始，让记录跟着实际进展生长。
