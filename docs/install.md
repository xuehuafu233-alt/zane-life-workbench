# 安装、更新与回滚

## 推荐：让 AI 引导

1. 下载[人生套装 0.4.1](../downloads/zane-life-suite-0.4.1.zip)并解压。
2. 在支持读取本地文件的 AI 软件中提供解压目录，说：“读取开始使用.md，帮我安装人生经营工作台，再处理我的第一个问题。”
3. AI 核实实际 Skill 目录后，使用包内安装器；安装完成后重载宿主或开启新会话，再提出真实问题。

安装包和你自己的工作台放在不同目录。前者是方法与工具，后者保存你的材料和进展。

## 本地安装命令

在解压后的 `zane-life-suite-0.4.1` 目录内运行；把路径替换成宿主实际使用的 Skill 目录：

```bash
python3 install.py --skills-dir "<宿主实际Skill目录>"
```

例如 Codex 通常通过 `~/.agents/skills/` 发现 Skill，Claude Code 可使用 `~/.claude/skills/`；由当前宿主核实。如果这两个入口已由同一套同步工具管理，只在真源安装一次，沿用原同步方式。Windows 按本机 Python 入口使用 `python` 或 `py`，其操作系统实测尚未完成。

请运行下载套装内的安装器。仓库根目录是公开说明、源码与下载入口，不作为安装器的完整性校验目录。

## 上传自定义 Skill

若软件支持上传 ZIP，依次上传[组件目录](skill-inventory.md)里的五个文件。单独上传人生总控不能替代其余依赖；部分网页宿主可能不允许跨 Skill 文件访问或执行脚本，需要按实际能力接续。

| 使用方式 | 能提供什么 | 验证情况 |
|---|---|---|
| macOS 本地文件与 Python | 安装、保存、事项工具、读取接续 | 安装器和本地工具已验证；实际 AI 表现按模型而异 |
| Codex / Claude Code 等本地 Agent | 读取 Skill 与用户文件，按实际工具执行 | 目录与权限由宿主确认；不等于每种软件组合都已实测 |
| WorkBuddy、豆包等支持自定义 Skill 的宿主 | 按该软件的上传、文件与工具能力使用 | 本版未逐端实测 |
| Windows | 按宿主目录与 Python 入口安装 | 未实测 |
| 纯聊天或手机聊天 | 使用方法、复制成果与接续摘要 | 不等于自动保存或跨会话永久记忆 |

## 更新

下载新版完整套装，解压到新目录，先让 AI 比较已有安装。相同文件可以复用；由本安装器管理且没有本地修改的旧版，可用：

```bash
python3 install.py --skills-dir "<宿主实际Skill目录>" --upgrade
```

工具在替换前保留检查点。未知来源的旧目录、被你改过的文件或不一致的软链会停止，让 AI 先保留并比较。早期三个 Skill 可能由网页或其他工具安装，不要直接覆盖；把确认属于旧包的目录备份到发现目录之外，合并自定义内容后再安装。

旧 0.3 人生包包含商业总控；0.4.1 人生版独立为五个组件。升级不会自动删除商业组件或个人材料。其他套装共装时比较共享组件，拒绝直接降级。

## 回滚

安装器会输出检查点位置。需要恢复时，用同一个新版安装器运行：

```bash
python3 install.py --skills-dir "<宿主实际Skill目录>" --rollback "<该目录下的检查点>"
```

若之后又安装过其他版本或改过文件，工具会停止，避免覆盖新工作。回滚保留被替换的新版本。网页上传与手工安装由宿主处理，更新前自行导出旧版，不能套用本地安装器的回滚保证。

下载校验值见 [SHA256SUMS](../downloads/SHA256SUMS)。完整套装和五个上传包分别有摘要。
