# 验证范围与自行检查

本版为人生经营套装，包含五个Skill：人生总控、搭建与维护、问题转译、AI伙伴设定、自我认识。模型及宿主能力影响实际使用。

## 已有验证

2026-09-12，在macOS本地环境完成安装、升级、回滚与文件一致性检查；工作台相关自动回归通过60项。AI合成场景走过从零帮助、保存、独立新上下文读取以及新事实纠错；另有同一合成故事的三次连续接续。历史快照曾遗漏一个被引用来源，已修复该次合成文件。

这些记录证明特定流程能运行，不等于陌生真人效果或优于普通助手。尚未证明长期生活改善、英语学习效果、求职结果或收益，也没有完成Windows、全部网页宿主和手机端实测。

## 你可以怎样检查

先用一个真实而可承受的问题，看看是否得到当下能用的帮助。请AI保存必要背景，下次只提供工作台位置；再补一个变化，观察它是否真正修改旧安排。无需为了检查填写完整人生档案。

安装器更新的是Skill目录；个人工作台放在另外的位置。旧版有修改时先保留和比较，安装/升级/回滚见[升级与回滚](install.md)。普通聊天只能在实际具备的保存能力范围内接续。
